# GuidedWavePDIApp 文档

## 概述
GuidedWavePDIApp 是一个用于指导波 PDI (无损检测) 的应用程序，旨在提供一个直观的用户界面和高效的算法，以帮助用户在材料检测中获得可靠的数据。

## 特性
- **用户友好的界面**: 提供简洁的界面以便于用户操作。
- **实时数据处理**: 支持实时采集和处理数据。
- **多种检测方法**: 提供多种无损检测方法供用户选择。
- **参数设置灵活**: 用户可以自定义检测参数以满足不同需求。

## 安装
1. **克隆库**:
   ```bash
   git clone https://github.com/aj84s/aj84s-guided-wave-analysis.git
   ```
2. **进入目录**:
   ```bash
   cd aj84s-guided-wave-analysis
   ```
3. **安装依赖**:
   ```bash
   npm install
   ```

## 使用
- 启动应用程序:
  ```bash
  npm start
  ```
- 使用应用程序时，可以通过菜单选择不同的检测功能。

## 参数
- **波频率**: 设置指导波的频率。
- **采样率**: 自定义数据采集的频率。
- **检测区域**: 指定需要检测的区域。

## 快速比较功能
应用程序中提供了快速比较功能，用户可以在不同检测结果之间进行对比，以便更好地理解材料状态和属性。这一功能可以在“比较”菜单中找到。

请查看应用程序中的帮助文档以获取更多信息。
